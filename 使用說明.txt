長者互動科技｜四階段整合網頁 V2

【先開啟這裡】
1. 解壓縮整份 ZIP，保留各資料夾。
2. Windows 雙擊 start.cmd。它會使用目前 Codex 的 Python 或電腦已安裝的 Python 3。
3. 網站網址：http://127.0.0.1:8769
4. 保留啟動視窗，關閉它會停止網站。
5. 其他電腦需要 Python 3，或將整個資料夾放上支援 HTTPS 的靜態主機。
6. 手機的 localhost 是手機自己；手機使用必須另行部署 HTTPS。
直接開 index.html 可看部分介面，但拼圖／攝影機辨識需透過本機伺服器或 HTTPS。

【一個首頁，四個模組】
01 動動腦 brain：六個原 App Inventor 活動已重新寫成 JavaScript。
02 動動手 motion：沿用第11–13週攝影機、骨架、舉手計次、未動提醒及預錄影片觀察。
03 生活紀錄 life：喝水、飲食、走路手動／語音輸入及每日紀錄。
04 聊天分享 chat：仍為介面試用與固定回覆示意，沒有真正串接 LLM。
首頁是插畫入口；點選活動後，進入上方固定五個選單、下方切換內容的功能頁。上方「回首頁」會回到插畫入口；模組內「活動選單」只返回該模組選單。切換模組會結束正在進行的活動；已儲存紀錄保留，未儲存輸入不保留。

【01 的 .aia 怎麼處理】
.aia 是 App Inventor 專案，不是能被瀏覽器直接執行的格式。
這次保留原 .aia，沿用原本素材，把操作邏輯重新實作成 HTML/CSS/JS。
下載整合網頁就能玩，不用先裝 APK，也不需要在網頁內模擬 App Inventor。
原始教材放在 app-inventor 資料夾，動動腦頁下方可下載。

00 剝蘋果皮：每次左右滑動剝一條，放開後再滑；五條完成，最後為蘋果核心。
01 找小魚：條紋、圓點、無花紋三題，可聽題目。
02 水果歸位：拖入相同籃子；也可點水果再點籃子。
03 魚盤拼圖：六塊不規則碎片、虛線位置、近距離吸附；可點碎片再點目的地。
04 收衣服：襪子、褲子、裙子、毛巾、上衣，隨機不重複；掉下時衣架少一件；籃子可上下左右移動。
05 噴蚊子：直式藍底，蚊子上下飛並小幅左右游移；按住罐子或噴霧按鈕才噴，放開即停止。
   噴中後改變表情，點蚊子有聲音；泡泡僅為視覺效果，不計分。每回合5隻，也可提前結束。

【共同成果】
依日期彙整動動腦完成回數、動作計次事件、生活紀錄及聊天介面參與次數。
聊天只有輸入文字並結束體驗才記一筆「介面試用」，不會當作真實 LLM 聊天。
不在共同成果保存聊天內容或相機影像。
資料放在同一網站來源的 localStorage；沒有 Google Sheets／後端登入／跨裝置同步。
舊的8766、8767、8768預覽資料不會自動轉到8769，因瀏覽器將它們視為不同網站來源。
原先各階段資料夾保留；整合版在這個獨立資料夾內。

【驗證與界線】
已用滑鼠／指標完成六個遊戲，檢查衣物不重複、按住噴霧才命中、蚊子受擊狀態、共同成果與日期切換。
已驗證生活紀錄、聊天介面試用及模擬攝影機啟動資料能顯示在共同成果。
已檢查320、390、768、1440寬度無水平溢位。
真人動作準確度、實體手機觸控手感、語音及臺語辨識仍需場域測試。
Google Sheets 與 LLM API 尚未串接，介面不會假裝完成這兩項服務。
動作辨識是教學原型，不能當作可靠跌倒通報或醫療判斷。
