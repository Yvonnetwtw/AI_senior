第4部分：聊聊天，網頁介面 V1

解壓縮後將檔案保留在同一資料夾，開啟 index.html。
HTML：畫面結構；CSS：高對比直式版面；JavaScript：互動、文字與語音控制。

流程：選話題 → 查看開場問題 → 說話或打字 → 確認後送出 → 結束與回饋。
所有 AI 回覆均為明確標示的固定示例；送出文字不會呼叫 LLM。
「看回覆示意」只是查看後續版面，不是即時 AI 回應。
聊天與回饋目前不儲存、不上傳至專題伺服器。

語音輸入使用瀏覽器提供的 SpeechRecognition，可能由瀏覽器廠商的網路服務辨識。
不是已完成的 AI 語音服務，也未驗證臺語辨識。
需依實際裝置允許麥克風；正式手機部署使用 HTTPS。
不支援時可打字或用手機鍵盤語音。
「聽這一句」使用裝置 TTS；可用聲音依装置而異。

下一階段：後端管理 API 金鑰及額度，接上語音／LLM 回覆後，再啟用真正聊天。
不要將 API 金鑰放在此網頁 JavaScript。
