# 03 魚盤拼圖 教師教學指引

依削蘋果方式：編號流程 → 積木圖 → 變數 → 半成品模板 → 修改與新增 → 測試反思。以密集課程完成核心80%為目標，不要求學生從零排版或重做複雜動畫。

來源：AI03_FishPlatePuzzleV2.aia。原始檔未修改。教學圖片由此檔積木資料重排，不是編輯器截圖；不要將網頁版操作誤當此.aia功能。

## 流程與程式對應

| 編號與流程 | 對應積木區段 | 程式如何改變 |
|---|---|---|
| 1. 開始與底圖 | Start.Click（plate_259） | 開始程序開啟LayoutClock，計算scale、虛線底圖及六片位置，最後ready設真。 |
| 2. 選取碎片 | Piece1.TouchDown（plate_329） | ready且placed1為假，將active設1、Piece1.Z設10，讓選中的碎片在上層。 |
| 3. 拖曳碎片 | Board.Dragged（plate_384） | 依active選擇Piece0～5，按手指位移MoveTo，再MoveIntoBounds。 |
| 4. 放開吸附 | Board.TouchUp（plate_481） | 碎片左上角接近目標X、Y各26以內時吸附；placed設真、停用該片、count加1。否則返回起點。 |
| 5. 查看提示與完成 | Hint.Click（plate_293） | Hint顯示完整盤面，Return回遊戲且不清除進度；6片完成後停用ready並顯示成果。 |

## 變數說明

| 變數 | 初始值 | 圖片解說時的提問／意義 |
|---|---|---|
| active | -1 | 目前拖曳的碎片0～5；-1未選取 |
| count | 0 | 拼好數量，6片完成 |
| ready | 假 | 排版完成才為真，允許互動 |
| placed0～5 | 假 | 每片是否已就位 |
| scale | 1 | 依畫布計算的圖片縮放比例；本堂先保留 |

## 學生模板與作業

發給學生：PuzzleStudentV1.aia。教師完成版最後才用於核對。空缺事件有任務註解；未補完時相關功能不會運作。

1. ② 仿Piece0.TouchDown補Piece1.TouchDown，正確使用placed1、active=1與Piece1.Z。
2. ⑤ 補Return.Click：只回到GamePanel，不呼叫開始，不重設count。

必改：把吸附容許距離26調整為另一數值；六片的X與Y上下界一致修改，試玩比較。

進階新增（核心完成後）：在Hint.Click加入一段語音，提示先看魚身花紋和盤緣。

## 驗收與除錯

- 等待排版後才可選片
- Piece1可拖且不被其他片遮住
- 接近虛線位置可吸附
- 已拼好的片不重複計數
- 查看提示再返回保留進度
- 6片完成後可重玩

除錯：提示返回後歸零：誤呼叫開始。碎片放好仍可重算：查placed與Enabled。難吸附：查26容許值及目標座標。

交件：學生.aia、操作錄影，以及一項修改前後的說明。每週反思使用同資料夾純文字版。

驗證界線：已核對原始XML、素材、模板指定空缺及輸出檔案；尚未實際登入App Inventor匯入或實體iPhone試跑。上課前教師請先匯入學生版，確認積木顯示與起始畫面。圖片大小與手機效果須另測，不能把XML檢查視為手機測試。
