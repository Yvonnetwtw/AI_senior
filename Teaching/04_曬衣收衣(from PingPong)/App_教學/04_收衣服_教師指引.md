# 04 收衣服 教師教學指引

依削蘋果方式：編號流程 → 積木圖 → 變數 → 半成品模板 → 修改與新增 → 測試反思。以密集課程完成核心80%為目標，不要求學生從零排版或重做複雜動畫。

來源：AI04_LaundryCatchV5.aia。原始檔未修改。教學圖片由此檔積木資料重排，不是編輯器截圖；不要將網頁版操作誤當此.aia功能。

## 流程與程式對應

| 編號與流程 | 對應積木區段 | 程式如何改變 |
|---|---|---|
| 1. 開始與擺放 | Start.Click（laundry3_329） | 開始重設used與mask，LayoutClock配置籃子衣物並啟動FallClock。 |
| 2. 抽出下一件 | 程序 下一件（laundry3_8） | 隨機挑slot，再跳過已使用項；標記used，更新mask及衣架背景。此複雜程序先提供。 |
| 3. 移動籃子 | Board.Dragged（laundry3_411） | Basket.TouchDown令dragging為真；Board.Dragged在running且dragging時更新X、Y；放開設假。 |
| 4. 下落與接住 | FallClock.Timer（laundry3_429） | FallClock每次將衣物Y增加Board.Height×0.018，再判斷是否進入籃子；接到加1。 |
| 5. 漏接與完成 | Home.Click（laundry3_385） | 漏接把同一衣物移回上方，不重新抽；接滿5件停止時計並顯示成果；Home停止計時並回首頁。 |

## 變數說明

| 變數 | 初始值 | 圖片解說時的提問／意義 |
|---|---|---|
| running | 假 | 遊戲與下落是否執行 |
| dragging | 假 | 手指是否正在操作籃子 |
| count | 0 | 接住數量，5件完成 |
| slot | 0 | 目前衣物位置0～4 |
| used0～4 | 假 | 這件是否已選出下落，避免重複掛出 |
| mask | 0 | 以1、2、4、8、16累加，選擇對應衣架背景 |
| kind | 1 | 此版仍宣告但未使用；不作本堂核心 |

## 學生模板與作業

發給學生：LaundryStudentV1.aia。教師完成版最後才用於核對。空缺事件有任務註解；未補完時相關功能不會運作。

1. ③ 補Board.Dragged：running且dragging時更新Basket.X與Y，並MoveIntoBounds。
2. ③ 補Board.TouchUp：dragging設假。

必改：調整FallClock下落係數0.018，比較較慢與較快版本；每次只改一個參數。

進階新增（核心完成後）：在接到衣服的分支加入簡短語音回饋；觀察是否過度頻繁，再決定保留方式。

## 驗收與除錯

- 開始後才下落
- 按住籃子可上下左右移動
- 衣物掉下時衣架少一件
- 漏接重來的是同一件
- 五件不重複且完成後停止
- 重玩重新掛滿五件

除錯：籃子不動：查dragging與Dragged。衣架重複：查used與mask，勿自行簡化下一件程序。完成仍落下：查FallClock.TimerEnabled。

交件：學生.aia、操作錄影，以及一項修改前後的說明。每週反思使用同資料夾純文字版。

驗證界線：已核對原始XML、素材、模板指定空缺及輸出檔案；尚未實際登入App Inventor匯入或實體iPhone試跑。上課前教師請先匯入學生版，確認積木顯示與起始畫面。圖片大小與手機效果須另測，不能把XML檢查視為手機測試。
