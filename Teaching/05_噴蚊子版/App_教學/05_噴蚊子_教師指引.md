# 05 噴蚊子 教師教學指引

依削蘋果方式：編號流程 → 積木圖 → 變數 → 半成品模板 → 修改與新增 → 測試反思。以密集課程完成核心80%為目標，不要求學生從零排版或重做複雜動畫。

來源：AI05_MosquitoNativeV4.aia。原始檔未修改。教學圖片由此檔積木資料重排，不是編輯器截圖；不要將網頁版操作誤當此.aia功能。

## 流程與程式對應

| 編號與流程 | 對應積木區段 | 程式如何改變 |
|---|---|---|
| 1. 開始與停止 | Button1.Click（mosquito4_13） | Button1是開始：分數歸零、蚊子恢復原圖、Speed=3、running為真；泡泡時鐘先關閉。 |
| 2. 移動與噴霧 | 圖像精靈1.TouchDown（mosquito4_140） | 噴罐圖像精靈1可拖動；TouchDown只在running時啟用spraying與FoamClock，cooldown歸零。 |
| 3. 放開停止 | 畫布1.TouchUp（mosquito4_155） | 噴罐與畫布的TouchUp都要把spraying設假、關閉FoamClock並清除畫布上的泡泡。 |
| 4. 泡泡與命中 | FoamClock.Timer（mosquito4_161） | FoamClock畫泡泡只是視覺；命中另以蚊子與噴罐的座標區域判斷，還須stunned為假且cooldown=0。命中加5並換暈眩圖。 |
| 5. 恢復與聲音 | ReactionClock.Timer（mosquito4_768） | ReactionClock解除stunned，恢復圖案與移動；ball.TouchDown播放TouchSound。Button2結束、PauseButton暫停／繼續。 |

## 變數說明

| 變數 | 初始值 | 圖片解說時的提問／意義 |
|---|---|---|
| score | 0 | 命中加5，顯示分數 |
| running | 假 | 是否在遊戲中 |
| spraying | 假 | 是否按住噴霧罐 |
| cooldown | 0 | 命中後設10，以FoamClock事件逐次減1；不是秒數 |
| stunned | 假 | 蚊子是否受擊暫停；ReactionClock後恢復 |

## 學生模板與作業

發給學生：MosquitoStudentV1.aia。教師完成版最後才用於核對。空缺事件有任務註解；未補完時相關功能不會運作。

1. ② 補圖像精靈1.TouchDown：running時spraying真、cooldown=0、FoamClock啟用。
2. ③ 補圖像精靈1及畫布1兩個TouchUp：停止噴霧、關閉時計、清除泡泡。

必改：調整蚊子Speed=3的所有恢復／開始位置，避免受擊後又變回舊速度。

進階新增（核心完成後）：在結束按鈕Button2加入Voice語音讀分數；原版沒有Voice元件，先於Designer新增TextToSpeech並命名Voice。

## 驗收與除錯

- 未開始無泡泡且不計分
- 按住才噴、放開立即停止
- 命中才加5並換表情
- 泡泡本身不加分
- 受擊後恢復飛行
- 點蚊子有聲音
- 暫停／結束後不繼續噴

除錯：滿畫面泡泡：查初始化及兩個TouchUp。重複加分：查cooldown與stunned。噴中不計分：查座標範圍與running。

交件：學生.aia、操作錄影，以及一項修改前後的說明。每週反思使用同資料夾純文字版。

驗證界線：已核對原始XML、素材、模板指定空缺及輸出檔案；尚未實際登入App Inventor匯入或實體iPhone試跑。上課前教師請先匯入學生版，確認積木顯示與起始畫面。圖片大小與手機效果須另測，不能把XML檢查視為手機測試。
