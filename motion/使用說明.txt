動動手｜HTML + CSS + JavaScript 網頁 V1
存放：02_第二階段_動動手_/web

依據 AI智慧健康照顧實務_18週課程規劃.docx 第11–13週製作。
保留使用者資料夾的「第二階段」命名；原課表稱第11–14週為第三階段業師課。

開啟：
1. 解壓縮，保留完整 vendor 資料夾。
2. 若電腦已安裝 Python 3，執行「啟動網頁.py」。
   或在此資料夾執行：python -m http.server 8768 --bind 127.0.0.1
3. 瀏覽器開啟 http://127.0.0.1:8768 ，建議 Chrome 或 Edge。
4. 選活動，按「開啟攝影機」，允許相機權限。
   直接雙擊 index.html 只能可靠地看介面，完整辨識請透過伺服器。
5. 手機使用需部署至 HTTPS 網址；手機 localhost 指手機自己，不是電腦。

第11週：看見我的動作
- 顯示上半身肩、肘、腕、髖的點線與最低可見度。
- 可見度不是正確率。光線、距離、遮擋及鏡頭固定方式要另外觀察記錄。
- 原課程失準紀錄與固定拍攝方式：使用「課堂測試紀錄」填寫，可匯出 CSV。

第12週：坐著舉舉手
- 預設觀察使用者左手，教師可改右手。
- 先放下（40度以下）、側抬（100度以上）、再放下，才完成一次。
- 抬手角度為髖－肩－肘，以肩為頂點。另顯示肩－肘－腕的手肘角度。
- 使用影像寬高比校正的2D角度，不是醫療級三維關節量測。
- 預設5幀平均，每個狀態至少維持400毫秒；均可設定。
- 遮擋或可見度不足時，重設動作階段但保留已完成次數，避免遮擋後直接加分。
- 語音報數使用瀏覽器／裝置TTS；實際可用聲音需實機確認。

第13週：動一動提醒
- 觀察上半身位置是否維持，沒有自動判斷「坐姿」或醫療上的久坐。
- 位移以肩寬正規化，預設低於0.08肩寬持續30秒，進入5秒取消窗。
- 示範時間30秒非健康建議。可在教師設定調整。
- 取消窗內可按取消或明顯移動取消。提醒後不連續轟炸，移動後重新計時。
- 人離開、身體遮擋、影片暫停或切換視窗都會重設持續時間。

教師預錄影片：
- 由教師選擇本機影片，未內附跌倒影片。不要要求長者現場跌倒。
- 以骨架身體中心在800ms內下降超過畫面高度0.12、軀幹傾斜超過60度持續700ms的簡化規則標記候選事件。
- 僅供講解「條件→持續→事件→人工確認」，容易受攝影角度、畫面構圖及遮擋影響。
- 沒有外部通知、求救通報或可靠跌倒警報功能。
- 影片中的候選事件附時間寫入測試紀錄，教師可記錄誤判／漏判。

資料與限制：
- 模型與依賴已放在 vendor，本機推論不需要 LLM token 或 API 金鑰。
- 影像不錄影、不上傳；僅測試文字、事件、時間與參數存在此瀏覽器。
- Google Sheets 尚未串接。
- CPU辨識節流至約每90ms一次；慢裝置可能更低。
- 單人上半身示範，尚未通過真人、不同手機與長者場域驗證。
- 已驗證模型初始化、合成攝影機影格、狀態判斷、匯出與響應式排版。
