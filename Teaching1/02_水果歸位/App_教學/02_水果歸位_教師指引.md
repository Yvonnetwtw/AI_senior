# 02 水果歸位 教師教學指引

依削蘋果方式：編號流程 → 積木圖 → 變數 → 半成品模板 → 修改與新增 → 測試反思。以密集課程完成核心80%為目標，不要求學生從零排版或重做複雜動畫。

來源：FruitHomeV1.aia。原始檔未修改。教學圖片由此檔積木資料重排，不是編輯器截圖；不要將網頁版操作誤當此.aia功能。

## 流程與程式對應

| 編號與流程 | 對應積木區段 | 程式如何改變 |
|---|---|---|
| 1. 開始與排版 | Start.Click（fruit_130） | 呼叫「開始」後開啟LayoutClock；計時事件依Board尺寸擺好水果與籃子，重設count、active及placed。 |
| 2. 選取水果 | Fruit1.TouchDown（fruit_166） | Fruit1.TouchDown檢查placed1為假，才把active設1。 |
| 3. 跟隨拖曳 | Board.Dragged（fruit_180） | 依active決定移動哪顆水果；位置加上currentX-prevX及currentY-prevY，並限制在畫布內。 |
| 4. 放開配對 | Board.TouchUp（fruit_229） | 依水果中心是否進入對應籃子範圍判斷；正確吸附並鎖定，錯誤回原位。 |
| 5. 完成與重玩 | Again.Click（fruit_132） | 每次正確count加1；3個完成。放開結束active回-1；重玩呼叫開始，重新排版。 |

## 變數說明

| 變數 | 初始值 | 圖片解說時的提問／意義 |
|---|---|---|
| active | -1 | 目前拖哪個水果；0、1、2是水果，-1是未選取 |
| count | 0 | 已放對幾個，3個完成 |
| placed0～2 | 假 | 各水果是否已放好，避免再次選取和重複計數 |

## 學生模板與作業

發給學生：FruitStudentV1.aia。教師完成版最後才用於核對。空缺事件有任務註解；未補完時相關功能不會運作。

1. ② 參照Fruit0.TouchDown，完成Fruit1.TouchDown：placed1為假時active設1。
2. 保留教師提供的座標、拖曳與命中範圍運算；用手機測出Fruit1補前補後的差異。

必改：修改錯放提示，使提示引導觀察籃子圖案。

進階新增（核心完成後）：在Fruit1選取成功分支加入Voice.Speak，播放「拖到一樣圖案的籃子」。

| 引導 | ARCS | 教師話術／學生行動 |
|---|---|---|
| 看成品 | A注意 | 先示範一次，請學生指出操作後哪個畫面改變。 |

| 改一個設定並測試 | C信心、R關聯 | 修改錯放提示，使提示引導觀察籃子圖案。 |
| 展示及回饋 | S滿足 | 展示補前補後差異；指出自己完成的積木，解釋少了它會怎樣。 |

## 驗收與除錯

- 三顆初始位置正確
- Fruit1可選取與拖動
- 放錯籃子回原位、不加數
- 放好後不能再次拖起加數
- 3個完成且重玩全部重設

除錯：水果不動：查active。放對仍回去：查對應籃子與中心座標。重玩不能拖：查placed與Enabled是否重設。

交件：學生.aia、操作錄影，以及一項修改前後的說明。每週反思使用同資料夾純文字版。

驗證界線：已核對原始XML、素材、模板指定空缺及輸出檔案；尚未實際登入App Inventor匯入或實體iPhone試跑。上課前教師請先匯入學生版，確認積木顯示與起始畫面。圖片大小與手機效果須另測，不能把XML檢查視為手機測試。
